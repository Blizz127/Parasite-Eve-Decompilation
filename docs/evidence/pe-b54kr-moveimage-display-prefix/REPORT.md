## Native GPU contract and honest fence

`PE_GPU_MoveImage` accepts arbitrary rectangle values under the current GPU
authority; it contains no address, function, or state test specific to this
overlay. It requires GP0 ready and idle, DMA2 idle, and GP1 DMA direction 2.
Coordinates are masked to 10/9 bits. Dimensions use the retail copy-command
formula `((raw - 1) & mask) + 1`, including raw zero as 1024 or 512. Source
and destination wrap independently on both axes.

Horizontal copies run right-to-left when the source starts left of the
destination; rows run top-to-bottom. The direction is independently described
as console-verified in DuckStation's software rasterizer at commit
`b0f7c5c1624d133d7c9e519d3b6f5ebb04b80c58`,
[`CopyVRAMImpl`](https://github.com/stenzek/duckstation/blob/b0f7c5c1624d133d7c9e519d3b6f5ebb04b80c58/src/core/gpu_sw_rasterizer.inl#L1833-L1938).
PSX-SPX independently documents the 10/9-bit masks, zero-as-maximum copy
dimensions, and independent X/Y wrapping in its
[`GPU Memory Transfer Commands`](https://psx-spx.consoledev.net/graphicsprocessingunitgpu/#gpu-memory-transfer-commands).

The retail worker starts linked-list DMA2. Native executes this authenticated
single packet synchronously and publishes only value telemetry. It creates no
DMA2 token, DICR edge, or callback. That is an intentional bounded limitation:
the canonical packet has deterministic final pixels before the following
DrawSync, but this rung does not claim asynchronous linked-list timing.
Likewise, the current GP0 subset does not claim general mask-bit modes.

`func_80076B98` rejects guest spans smaller than five words and any tag or
command other than the exact MoveImage packet before changing VRAM. Those
cases stop at `func_80076B98_packet_span` or
`func_80076B98_packet_cut`. No linked-list traversal or guest command-stream
interpreter was introduced.

Both existing retail paths are exercised:

- direct dispatch through `func_80076C34`, including saved-I_MASK restore;
- a guest-ring entry consumed by `func_80076EE4`, including ordinary worker
  return, consumer publication, and mask restore.
